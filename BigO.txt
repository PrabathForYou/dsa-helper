"How code slows as data grows"

Describes the performance of an algorithm as the amount of data increases

O : order
n : how much data passes


-- O(n) Linear time

int addUp(int n) {
    int sum = 0;
    for(int i = 0; i <= n; i++) {
        sum += i;
    }

    return sum;
}

n = 100000
100000 steps

this function does have run time complaxity of O(n) .

-- O(1) Constant time

int addUp(int n) {
    int sum = n * (n + 1) / 2;
    return sum;
}

n = 100000
3 steps
